# Python Algorithm and Game

A collection of Python programs including searching algorithms, divisor algorithm, and odd/even games.

 Features

### Binary Search Algorithm
- Searches for a number within a sorted list.
- Uses the efficient Binary Search method.
- Returns the index of the searched number if found.
- Returns `None` if the number is not in the list.

### Divisor Finder
- Accepts a number from the user.
- Finds and displays all divisors of the number.
- Demonstrates loops, conditions, and list operations.

###  Odd or Even Guessing Game
- The user chooses either **odd** or **even**.
- The computer randomly guesses.
- The program determines the winner based on whether the guess matches the user's choice.

### Odd or Even Number Game
- The user chooses **odd** or **even** and selects a number.
- The computer generates a random number.
- The sum of both numbers determines the winner.
